argument-hint: "[optional context or focus area]"
---

Invoke the `writing-pr-descriptions` skill.

- Compare the branch against the PR base branch (not just the last commit) to get the full scope of changes.
- Write a description with four sections, in order: What it does, Rationale, Implementation, Testing instructions.
- Follow the skill's guidelines: be specific, explain rationale, note stacked-PR scope/non-goals when relevant, use inline `code`, show code examples for complex changes, avoid buzzwords and emojis.
